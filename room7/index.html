Как пользоваться

  1. Откройте сайт в кабинете № 7, включите камеру и разрешите доступ.
  2. Покажите участок помещения с узнаваемыми деталями. Задержите телефон на месте, пока сайт определяет ракурс.
  3. Коснитесь подписи для просмотра карточки. Чтобы проверить ориентиры издалека, выберите «Без ограничения».

Кнопка «Проверить по фото» позволяет выбрать один снимок помещения из галереи.
